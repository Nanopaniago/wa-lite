Ligação n8n

Receber mensagens

Cada mensagem recebida é enviada por POST para o N8N_WEBHOOK_URL. Crie um nó Webhook no n8n com método POST. Exemplo do corpo:

{
  "event": "message",
  "chat": "351912345678@s.whatsapp.net",
  "chatName": "Marta Silva",
  "from": "351912345678@s.whatsapp.net",
  "text": "Olá!",
  "type": "text",
  "isGroup": false,
  "timestamp": 1760480000
}
